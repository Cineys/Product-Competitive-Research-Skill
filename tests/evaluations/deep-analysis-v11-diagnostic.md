# V1.1 深度分析证据诊断补充

日期：2026-10-11。对应同日保存的深度分析运行记录。本文件补充诊断结论，不覆盖原始事件、模型回答或此前报告。

## 重定向来源更正

此前依据精简的 `results/events.jsonl`，曾将最终报告中的 `https://www.bilibili.com/opus/425087778171832965` 判断为未读取来源，并列为 P0。该结论撤销。

原始 Codex session rollout 记录显示，模型实际打开 `https://www.bilibili.com/read/cv7230899/`，工具将其重定向到上述 `opus` URL，返回 840 行正文，并随后在该页面查找“视频笔记功能”。精简事件只保留请求 URL，没有保留 redirect target，导致审计误判。该问题归类为日志粒度造成的审计观测误差，不是 Skill 未遵守正文读取规则。后续审计应同时检查请求 URL、原始工具返回中的重定向目标和正文记录。

## 仍保留的问题

最终报告把 B站域名下的历史文章称为“B站官方历史功能说明”。现有日志能确认页面正文和发布账号名称，但不足以确认账号的官方认证或发布主体关系。该问题保留为 P1：官方域名不等于官方发布主体，平台站内用户内容不能仅凭域名、标题或语气升级为官方文档。

本次诊断不改变该单次运行对深度分析能力的其他结论，也不证明模型行为具有稳定性。
